**What to use**

- Square (1:1). 600 × 600 px is plenty; anything larger is wasted bandwidth.
- `.jpg` with the exact file name above, all lower case. The page looks for that name.
- Head and shoulders, centred, with the face in the middle third, because the photo is shown as a circle.
- Keep each file under about 200 KB.

Until a photo is added, that person's card shows their initials in the RCS blue. Nothing breaks, and the layout does
not move: the page never shows a broken image. To change a photo, replace the file and keep the name.
